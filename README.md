# for1 — AI 개발 실습실 (BUILD / 90)

AI에게 개발을 맡기고, 내가 결과를 확인합니다.
8개 과정·90개 미션으로 구성된 AI 개발 교육 및 실습 프로그램입니다. 기본 실습은 10~15분이며, 어려운 확장 과제는 선택 심화로 나누었습니다.

## 처음 시작하실 때

1. 「오늘 할 일」에서 작은 목표 하나와 시작 화면을 읽으세요.
2. 「작은 실습 시작」에서 세 단계를 따라 해 보세요. 복사 가능한 AI 요청을 GPT Work 또는 Claude의 새 대화에 붙여 넣으셔도 됩니다.
3. 「성공 확인」에서 결과를 직접 확인하고 두 항목을 표시한 뒤 완료하세요. 과정 전체 퀴즈와 심화는 선택입니다.

1일차는 저장소의 파일 이름과 상품 제목 읽기만 합니다. 제목 변경·커밋·Diff·브랜치·병합·복구는 별도 미션에서 배웁니다. Git 전체 연습 기능은 선택 심화에서 열 수 있습니다.

모든 예시는 가상 상품·가상 사용자입니다. 안티그래비티나 다른 앱의 실행 중인 에이전트에 명령하거나 실제 고객정보를 입력할 필요가 없습니다. 실제 GitHub·Vercel 업로드도 기본 과제에 포함하지 않습니다.

기존 `build90-v1` 저장 키, DAY 1–90, 완료 날짜와 날짜별 메모, JSON 내보내기 형식을 유지합니다. 다른 브라우저나 `file://`·`localhost`처럼 다른 주소에서는 기록이 따로 보관됩니다.

## 📌 주요 특징
- **8개 과정, 90일 과제**: 체계적인 커리큘럼 기반 인터랙티브 실습
- **브라우저 내장 SQLite**: sql.js 기반 실시간 SQL 쿼리 실습
- **Three.js & GSAP 기반**: 몰입감 넘치는 모던 UI/UX 인터랙션
- **완전 무과금 로컬 환경**: 외부 API 키 없이 브라우저 단독 실행 및 로컬스토리지 기록 저장

## 🚀 로컬 실행 방법
```bash
npm install
npm run dev
```

## 🛠️ 프로덕션 빌드
```bash
npm run build
```

단일 파일로 열려면 빌드 후 `node scripts/standalone.mjs`를 실행하고 `BUILD90-교육페이지.html`을 여세요.

## 검증과 수정 위치

`npm test`는 8개 과정/90개 미션의 식별자·완전성·기존 저장 기록 호환성을 확인합니다. 별도 TypeScript 설정이나 타입 검사 명령은 없습니다. JSX 구문과 번들은 Vite 빌드로 확인합니다.

| 파일 | 역할 |
| --- | --- |
| `src/curriculum.js` | 과정, 기존 날짜·제목·개념, 작은 과제 요약 |
| `src/mission-guides.js` | 미션별 목표·이유·시작 화면·세 단계·AI 요청·결과·성공 기준·도움·심화 |
| `src/mission-ui.jsx` | 단계별 안내, 요청 복사, 선택 심화 화면 |
| `src/learning-state.js` | 기존 저장값 호환과 손상된 값의 안전한 읽기 |
| `src/main.jsx` | 탐색·기록·직접 확인 후 완료 |
| `src/labs-*.jsx` | 가상 실습 및 실제 SQLite 실습 |

SQL은 브라우저 안의 실제 SQLite입니다. Git·API·Docker·구조·RAG·Agent·Eval은 학습 모형입니다. 실제 API 호출이나 모델 성능 측정, 운영 서버 실행을 하지 않습니다. 외부 글꼴을 못 불러와도 시스템 글꼴로 학습할 수 있습니다.
