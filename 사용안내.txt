BUILD / 90 — AI 개발 실습실

바로 사용: BUILD90-교육페이지.html 파일을 브라우저에서 여세요.
8개 과정, 90일 과제, 구조도, 실습 표, 집중 모드, 학습 타이머를 제공합니다.
학습일·완료 기록·실습 메모는 이 브라우저에만 저장됩니다.
기록 내보내기로 JSON 백업을 만들 수 있습니다.
모든 과정은 자유롭게 이동할 수 있습니다.

쉽게 시작하기
- 오늘 할 일: 작은 목표 하나·이유·시작 화면을 읽으세요.
- 작은 실습 시작: 세 단계를 따라 하고, 필요하면 AI 요청을 복사하세요.
- 성공 확인: 결과 두 가지를 직접 확인하고 완료를 누르세요.
- 기본은 10~15분입니다. 심화와 과정 전체 퀴즈는 선택입니다.
- 1일차는 파일 이름과 상품 제목만 읽습니다. Git 조작은 하루씩 나눠 배웁니다.
- 가상 상품·가상 사용자만 사용합니다. 실제 고객정보나 실행 중인 다른 프로젝트를 사용하지 마세요.
- GPT Work 또는 Claude 대화에서 예시·설명을 받습니다. 안티그래비티에 실제 조작을 명령할 필요는 없습니다.
- 저장 키와 기존 완료일·메모는 유지했습니다. 주소나 브라우저를 바꾸면 기록 저장 위치도 달라집니다.

실습 범위
- SQL: 실제 SQLite 엔진으로 실행합니다. 새로고침하면 실습 DB가 초기화됩니다.
- Git·API·Docker·아키텍처·RAG·Agent·Eval: 학습용 시뮬레이션입니다.
- 실제 GitHub·Supabase·GPU 서버·AI API에 연결하거나 변경하지 않습니다.
- RAG는 문자 검색 점수 예시이며 실제 임베딩 또는 LLM을 사용하지 않습니다.
- Eval 값은 합성 예시이며 실제 모델 성능이나 실제 비용이 아닙니다.
- 외부 폰트가 로드되지 않아도 시스템 글꼴로 이용할 수 있습니다.
